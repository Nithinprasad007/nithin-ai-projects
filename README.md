# Nithin AI Projects 🚀

## ⚙️ Getting Started

Clone the monorepo to explore each project:

```bash
git clone [https://github.com/Nithinprasad007/nithin-ai-projects.git](https://github.com/Nithinprasad007/nithin-ai-projects.git)
cd nithin-ai-projects
```

Navigate into either project subfolder for dedicated setup instructions, environment variable configurations, and dependency installation guides.
