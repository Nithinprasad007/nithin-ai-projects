# AI Projects

A collection of small, self-contained AI-powered tools and experiments.

## Projects

- [resume-job-matcher](./resume-job-matcher) — Local-LLM resume-to-job-description fit analyzer with deterministic, evidence-based scoring (via Ollama + Streamlit).
- [browser-mcp-agent](./browser-mcp-agent) — Autonomous multi-turn browser automation agent with live DOM grounding, persistent Chromium sessions, and local Ollama inference (via MCP + Streamlit).

More projects will be added here over time — each lives in its own folder with its own README and requirements.
